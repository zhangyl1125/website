# 2026-09-08 第三轮界面调整与验证

## 已实现

- 顶部导航背景透明；悬停和键盘聚焦显示浅色高亮与箭头，尊重减少动画设置。
- 首页 Logo 下方字形通过原图透明蒙版显示白色至浅灰色渐变；原图文件、上部图案及透明轮廓保留。
- 候选人列表改为单列横向卡片，左侧照片、右侧报名信息。信息支持鼠标滚轮、触摸和键盘滚动，详情按钮查看完整内容。
- 浏览与投票页面移除评论模块和入口，不再请求评论接口；保留历史评论数据。
- 我的点赞面板透明，右上角增加一键清空。点赞、撤票、清空即时同步；失败时保留原状态并显示错误。
- 桌面左侧页面与右侧点赞面板可独立操作；手机打开面板时分为上下两个滚动区域，避免透明面板与底层文字重叠。
- 评选管理标题和说明改为白色，奖项卡片透明。管理员可搜索、查看、创建、编辑和删除奖项；删除操作确认后执行。
- 补齐 DELETE /api/v1/hackathons/{id}，仅 ADMIN 可调用；适用于 draft、open、running、completed 全部状态。现有数据库外键级联删除对应报名、票数、评委、评分、团队等关联记录，不修改其他奖项。
- 新增 DELETE /api/v1/me/votes，从登录身份确定用户；在事务和投票人锁下清空本人全部奖项的点赞，数据库触发器同步计数。
- 修复编辑表单遗漏保存规则与横幅地址的问题；状态选项与后端已有状态流转一致，实际调用状态接口。资料与状态分两次保存时，状态失败会明确提示资料已保存。
