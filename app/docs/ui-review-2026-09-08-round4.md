# 第四轮修改与验证（2026-09-08）

## 投票问题

修正前端赛道归类：先对正式赛道名去除空格并忽略大小写，再回退到历史分类和标签判断，与后端保持一致。此前正式赛道名大小写不同且标签含其他赛道关键词时，页面可能显示到错误赛道，使用户看到的分类与后端额度不一致。尚不能确认这就是用户所遇错误的实际原因。

遇到“四票上限”响应时，改为中文说明已保存的历史点赞也占额度，自动打开我的点赞并重新读取服务端数据。面板按奖项及赛道显示已投票数，并提供清空本赛道入口；保留一键清空全部。清空失败保留原状态，成功后可重新选择。未调整每个奖项每赛道最多四票和跨部门比例规则，也未自动删除用户的已有投票。

临时 PostgreSQL 实测：四票后第五票被正确拒绝；撤回一票后可改投第五位；清空本赛道后可重新投四票；一键清空后可再次投四票；数据库票数与记录数一致。当前代码中未复现清空后仍占额度的问题，未连接线上数据，因此未声称已确认现场错误的全部原因。
