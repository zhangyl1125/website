# Website

Website workspace containing the application, specifications, and development resources.

- `app/`: application source and setup instructions; see [app/README.md](app/README.md).
- `SSD/`: requirements, design, and task documentation.
- `.agents/`: project development skills.
- Root `package.json`: Playwright development tooling.

Dependencies, build output, local editor settings, environment credentials, and private TLS keys are excluded. Supply local configuration before running the application.
